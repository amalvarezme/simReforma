# simReforma

Interactive simulator of the income-tax impact of Colombia's 2026 *Proyecto de Ley de Rescate Económico* on public-university professors (cédula general, labor income), compared with the current law.

**Live:** https://amalvarezme.github.io/simReforma/

## What it models

- Repeal of the 50% exemption of *gastos de representación* (ET art. 206 num. 9; bill art. 106 num. 1).
- Global cap of exempt income and deductions lowered from 1,340 to 1,180 UVT (bill art. 49) and the 25% exemption cap from 790 to 630 UVT (art. 47).
- New income-tax table with a 9% bracket (720–1,090 UVT) and 39% from 8,670 UVT (art. 48).
- Removal of the extra 72 UVT per dependent outside the cap (art. 106 num. 1).
- Employee health contribution from 2027 (art. 21): +1.5/+2.5 pp in special regimes, or the 4%–8% contributory table.
- Annual income = 12 monthly payments + *prestaciones* + *cesantías* (shares are adjustable).
- Base scenario: salaries rise with inflation (IPC). The *Aumentos según IPC* switch keeps both raises tied to the inflation slider; turn it off to set them manually.

Charts show monthly salary vs. annual tax over the projection, a background zone per year with the tax generated by each peso of raise (green < $0.90, orange $0.90–$1.10, red > $1.10), and the transition-year curve that finds the raise at which the extra tax equals the raise.

This is an academic exercise about a **bill** that may change in Congress. It is not tax advice.

## Development

```bash
npm install
npm run dev     # local server
npm test        # engine tests (vitest)
npm run build   # production build in dist/
```

The tax engine lives in `src/tax/engine.ts` and has no UI dependencies; the React UI is in `src/simulator/`. Pushes to `main` deploy to GitHub Pages through `.github/workflows/deploy.yml`.
